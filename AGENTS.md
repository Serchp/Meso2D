# AGENTS.md

## Project overview
- Python desktop application based on PyQt5 for mesostructure modeling, porous media generation, and visualization.
- The most current runnable entrypoint is `Meso2D_refactor.py`.
- Core GUI definitions are generated from Qt `.ui` files and stored in generated modules such as `Main03.py`, `Main_inicio.py`, and `dialog_GV.py`.

## Key files
- `Meso2D_refactor.py` — current main application entrypoint, uses `SimulationController` and `simulation_service` to select workers by mode.
- `GV.py` — custom `MiGraphicsView` helper for image display and zoom/pan behavior.
- `Main03.py`, `Main_inicio.py`, `dialog_GV.py` — PyQt5 UI code generated by `pyuic5`; avoid manual edits when possible.
- `Inicio.py` — older launcher example using `Main_inicio.py`.
- `Worker*.py` and `worker_base.py` — worker-related modules, including background processing for simulation.
- `obsoletos/` — legacy copies and experimental archives. Prefer root-level source files unless the task explicitly targets an obsolete variant.

## Conventions and guidance
- Preserve Spanish domain terms and variable names: `poros`, `aridos`, `pasta`, `dosificación`, `probeta`, `reactivos`, `estructura`, etc.
- Do not modify generated UI files manually unless the user asks for a direct patch. Prefer editing `.ui` sources and regenerating via `pyuic5` if available.
- The codebase mixes handwritten GUI logic with generated UI classes. Focus on `Meso2D_refactor.py` for application flow and `GV.py` for custom graphics behavior.
- Avoid sweeping refactors of legacy branches in `obsoletos/` without explicit user instruction.

## Dependencies
- `PyQt5`
- `numpy`
- `matplotlib`
- `ezdxf`

## Notes for AI agents
- There is no discovered `requirements.txt`, `setup.py`, or automated test suite in the repository.
- When adding or updating features, keep changes local to the active root-level branch and do not disturb archived experiments in `obsoletos/`.
- If asked to run or verify the application, use `python Meso2D_refactor.py` and expect a PyQt5 desktop GUI.
